# P4inz

P4inz is Northbyte Studios' open-source Discord intelligence and community platform.

It provides a structured way for community members to discover accurate information about Northbyte Studios, its projects, releases, documentation, and community resources.

## Goals

- Accurate and maintainable information
- Source-aware knowledge
- Permission-aware access
- Safe AI assistance
- Strong security
- Self-hostable infrastructure
- Zero mandatory recurring cost
- Long-term maintainability

## Technology

P4inz is built as a modular Rust workspace with:

- Rust
- PostgreSQL
- Discord integration
- Background workers
- Search/retrieval
- Optional AI providers
