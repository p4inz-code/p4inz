# Zero-Cost Infrastructure Policy

P4inz must remain functional without paid infrastructure.

Preferred options:
- GitHub
- Cloudflare Pages
- Cloudflare networking where appropriate
- self-hosted PostgreSQL
- Docker
- open-source Rust tooling
- local AI models where practical

Paid providers may be supported through abstractions but must never become mandatory.

Every external dependency should have a replacement or self-hosted path where practical.
